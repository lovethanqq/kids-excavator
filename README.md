## 🌟 游戏特色

1. **工业级 3D 机械挖掘机**：
   - 包含完整双履带底盘、回转支承、透明驾驶舱、双液压手柄、动力机舱、排气管烟雾粒子系统。
   - 全套液压铰接连动机构（折角大臂 + 双液压油缸与镀铬活塞杆 + 斗杆 + 4 齿合金耐磨铲斗）。
2. **零失败惩罚设计（符合 3 岁儿童认知心理）**：
   - 点错绝不扣分或 Game Over！挖掘机轻微摇摇头，语音亲切提示，正确目标发光跳动指引。
3. **真实挖掘动作与破土特效**：
   - 听到/看到目标数字后，挖掘机转向并驶向泥堆，液压轰鸣下铲，泥土碎屑粒子四散飞溅（破土特效），将发光 3D 数字铲入斗内并高高举起。
4. **多感官即时反馈**：
   - 原生 Web Audio API 合成：柴油机突突突怠速、加速轰鸣、液压升降、铲斗砸土破土声、双音喇叭声。
   - 内置中文真人语音播报引导。
   - 宝宝专属“📢 按喇叭”超大按钮。
   - 5 颗星通关大派对：全屏彩色烟花与挖掘机转圈跳舞。
5. **多难度模式**：
   - 1 - 3 萌宝模式
   - 1 - 5 进阶模式
   - 1 - 9 达人模式
